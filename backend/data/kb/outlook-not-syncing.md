# Outlook Not Syncing / Emails Not Arriving
Category: Email

## Resolution steps
1. Check the status bar at the bottom of Outlook. If it shows "Disconnected" or "Working offline", go to Send/Receive > Work Offline to toggle it off.
2. Check whether email works in Outlook on the web (`https://outlook.office.com`). If it does, the problem is the desktop app.
3. Close Outlook and restart it.
4. Repair the Outlook profile: Control Panel > Mail > Show Profiles > Add a new profile and set it as default.
5. Check that your mailbox is not full (limit 100 GB). Archive old emails if needed.

## Escalation
If Outlook on the web also does not receive emails, raise an **Email** ticket with priority High.
