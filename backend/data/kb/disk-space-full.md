# Disk Space Full
Category: Hardware

## Free up space
1. Run Disk Cleanup: Start > "Disk Cleanup" > select C: > Clean up system files.
2. Empty the Recycle Bin and the Downloads folder.
3. Set OneDrive files to "Free up space" so they are stored online only.
4. Uninstall applications you no longer use from Settings > Apps.

## Check usage
Use Settings > System > Storage to see which folders use the most space.

## Escalation
If the disk is still more than 90% full, raise a **Hardware** ticket; the laptop may need a larger disk.
