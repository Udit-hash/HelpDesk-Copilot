# Installing Software
Category: Software

## Approved software
Most approved applications (e.g. Python, VS Code, Zoom, 7-Zip, Power BI Desktop) can be installed without admin rights from the **Software Center**.

## Software not in the Software Center
1. Raise a **Software** ticket with the application name, version, and business reason.
2. Licensed software needs your manager's approval and a cost center.
3. Security reviews new software; this usually takes 3 to 5 working days.

## Admin rights
Local admin rights are not given by default. Developers can request temporary elevation for 24 hours through the IT Self-Service portal.
