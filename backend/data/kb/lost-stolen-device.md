# Lost or Stolen Laptop or Phone
Category: Hardware

## Act immediately
1. Call the Service Desk 24x7 line straight away so the device can be locked and wiped remotely.
2. Change your password using the self-service portal.
3. For theft, file a police report and keep the report number.

## Replacement
Raise a **Hardware** ticket with priority High. Include the asset tag (if known), date, location, and police report number. Replacement laptops are usually issued within 2 working days.
