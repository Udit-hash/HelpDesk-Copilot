# OneDrive Not Syncing

## Resolution steps
1. Click the OneDrive cloud icon in the system tray and check for errors or a "Paused" status.
2. Make sure file names do not contain invalid characters (" * : < > ? / \ |) and paths are shorter than 400 characters.
3. Check your OneDrive storage (limit 1 TB).
4. Reset OneDrive: press Windows + R, run `%localappdata%\Microsoft\OneDrive\onedrive.exe /reset`, then start OneDrive again.

## Important
Always store work files in OneDrive or SharePoint, not only on the local disk; local files are not backed up.
