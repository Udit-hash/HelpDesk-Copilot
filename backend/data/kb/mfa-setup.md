# Multi-Factor Authentication (MFA) Setup
Category: Access

## Setting up MFA on a new phone
1. Install the Microsoft Authenticator app.
2. On a computer, go to `https://mysignins.example.com/security-info`.
3. Click "Add sign-in method" > "Authenticator app" and scan the QR code with your phone.
4. Approve the test notification.

## MFA prompts not arriving
- Check that notifications are allowed for the Authenticator app.
- Make sure the phone's date and time are set automatically.
- Use the 6-digit code shown in the app instead of the push notification.

## Lost or replaced phone
Raise an **Access** ticket asking for an "MFA reset". After the reset, register the new phone using the steps above within 24 hours.
